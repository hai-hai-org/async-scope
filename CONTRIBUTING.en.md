# Contributing

## Branch

- `main` — always deployable
- `feature/{description}`, `fix/{description}`, `docs/{description}`, `refactor/{description}`
- With an issue: `feature/12-timeline-viewer`

## Commit Message

Follows [Conventional Commits](https://www.conventionalcommits.org/).

```
<type>: <subject>
```

`type`: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`, `perf`, `style`

## Pull Request

1. Create a branch from `main`
2. Fill in the PR template checklist
3. Link the related issue with `Closes #issue-number`

## Issue

Use the Bug Report template for bugs and the Feature Request template for new feature proposals.
